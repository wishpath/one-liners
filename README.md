# one-liners
Console application for learning Software engineering concepts.

How it works:
- App prompts user to explain concept.
- Answer is evaluated.
- User is provided with notes and grade.
- App remembers the answer attempt.
- App plans which concept is the next to be asked based on the memory.

Technical:
- requirements: JDK 21
- update submodules after cloning: `git submodule update --init --recursive`
- run this class `src/main/java/org/sa/APP/MainApp.java`
