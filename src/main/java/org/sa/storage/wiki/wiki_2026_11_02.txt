*Goal of this article*
This set of very short definitions gets straight to the point, giving you the basics of each idea in just a few words. It’s a fast way to start learning and build confidence, even if the definitions aren’t perfect. The simple style helps you pick up many ideas quickly and gives you a base to learn more over time.


*Algorithms Coding And Structures*
     DRY - Don't Repeat Yourself — programming principle promoting avoidance of duplicate code or logic.
     DSL - Domain-Specific Language — syntax tailored to a non-general domain. Example: Thymeleaf provides DSL for HTML.
     Hungarian pollution - overusing type prefixes in variable names.
     abstraction - Process of hiding complex details, exposing only essential features to manage complexity.
     abstraction examples - interfaces, modules, packages, APIs, frameworks, ORMs, microservices, VMs, containers.
     boilerplate - sections of code that have to be included in many places with little or no alteration.
     cohesion - Degree to which elements of a module or class are related — aimed at achieving a single purpose.
     cohesion example - UserManager class with createUser, deleteUser methods — focused on single responsibility.
     collision - Different inputs producing identical hash codes.
     collision resistant - Different inputs should not produce the same outcome.
     contiguous - next to each other without gaps. pronunciation: /kənˈtɪɡjuəs/
     coupling (noun) (software) - Degree of interdependence between software modules.
     defensive programming - Ensuring software behaves as expected even when encountering unexpected inputs or conditions.
     deque - Double-ended queue maintaining insertion order, allows access at both ends, implemented in Java as ArrayDeque.
     deterministic - Same input will always produce the same outcome.
     directed graph - Nodes connected one-directionally.
     dispose of a list - Release the list and its resources.
     dispose of memory - Free up or release memory.
     edge (graphs) - Connection of two nodes.
     encapsulation - Hiding internal elements of object or service. Provides clear separation. Improves maintainability.
     factory pattern - Using a method to produce objects implementing a common interface.
     greedy solution - Picks best now, ignores future. Assumes local = global best.
     hash - Unique representation of input data. Deterministic, fixed size, irreversible.
     hash use cases - Data integrity, password storage, encryption, verification, indexing, quick lookups.
     hashing - Transforming data into fixed-size code; deterministic; collisions possible; irreversible;
     heap (data structure) - ordered data structure, in Java implemented as PriorityQueue. Good for efficient auto sorting.
     indegree - Number of incoming edges directed towards a node.
     irreversible data transformation - Not possible to obtain the original input from the outcome.
     justified vs excusable - Justified focuses on positives despite downsides; excusable tolerates known flaws.
     lazy initialization - Object creation delayed until first use, improving performance and reducing resource consumption.
     means of defensive programming - Input validation, error handling, robustness, fail-safe defaults, clear documentation, assertions, logging.
     memoization - Storing results of expensive function calls and returning the cached result when the same inputs occur again.
     outdegree - Number of outgoing edges directed from a node.
     parity - State of being even or odd.
     permutation - Specific arrangement of distinct elements.
     polymorphism (OOP) - Overriding and overloading; objects and methods take multiple forms via extending or implementing.
     proxy pattern - Proxy object controls access to real object, both share interface, with the proxy being used externally.
     state (of object) - Current values of fields.
     technical debt - Accumulated code imperfections.
     trie - Tree storing words by letters, good for fast prefix search. Pronounced like “try” (/traɪ/).
     undirected graph - Nodes connected bi-directionally.
     vertex - node in a graph

     REST client-server constraint - separates client (UI) and server (logic) responsibilities for independent evolution.

     RESTful layers - structured as controller, service, and data access layers
     RESTful methods - uses standard HTTP verbs: GET, POST, PUT, DELETE
     Swagger - framework that simplifies listing, designing, documenting, and testing RESTful web APIs
     URL - Uniform Resource Locator — standard way to identify and locate resources on the web
     non-semantic message - raw data with no context about its meaning, e.g., plain text, CSV row, raw byte stream
     semantic message - data and its explanation by metadata, e.g., JSON with field names as metadata and values as data
     using APIs - exchanging data and functionality between systems via predefined rules
